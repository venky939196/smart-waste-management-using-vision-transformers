# Smart Waste Management Using Vision Transformers

A smart waste management dashboard designed to classify and monitor waste streams using a vision transformer-inspired interface and modern web technologies.

## Features
- Waste classification overview
- Live monitoring dashboard
- Smart bin status summary
- Clean and responsive UI

## Tech Stack
- React
- Vite
- JavaScript

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
